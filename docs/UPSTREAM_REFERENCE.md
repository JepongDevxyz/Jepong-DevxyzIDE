# Upstream/reference notes

DevxyzIDE is being developed as its own branded project. The architecture is informed by public Android tooling documentation and mobile IDE projects.

- AndroidIDE (archived) demonstrated Gradle-on-Android, Termux terminal integration, language services, UI designer, Git and Android-host aapt2 override.
- Code On The Go is the actively maintained successor to AndroidIDE in 2026 and is used as a feature/architecture reference for future DevxyzIDE milestones.
- Sora Editor is the preferred modern editor engine candidate for syntax highlighting, completion, diagnostics and LSP integration.

No Code On The Go or AndroidIDE source code is copied into this v0.4 snapshot. If DevxyzIDE later directly incorporates GPL-licensed source, the resulting distribution must preserve the applicable GPL license and notices.
