# DevxyzIDE

Native Android IDE by Jepong Devxyz.

## Features
- Dark navy and cyan mobile workspace inspired by the DevxyzIDE reference
- Dedicated Files, Code, Build, Tools and Settings screens
- Secure ZIP project import with staging, Gradle project validation, Zip Slip protection and expanded-size limits
- Create a launchable Kotlin Android starter with Gradle 8.10.2 wrapper
- Edit and save source files, search, terminal, Git status, project backup/export
- Embedded toolchain diagnostics for JDK 17, Android SDK 35, AAPT2, AIDL, D8, zipalign and apksigner
- APK build and install flow
- Android CI compiles, tests, checks the APK package and signature, and uploads a debug APK

The generated starter targets Android SDK 35, uses AGP 8.8.2 and Kotlin 2.1.10, and has a launcher activity. A working toolchain (JDK 17 and Android SDK 35) and network access for the Gradle distribution and Maven dependencies are needed for the first build.
